# Human Photobooth

Simple Halloween photobooth for an iPad: tap, 3-2-1, framed 2x3 photo, print
to a Kodak Mini 2 Retro via the share sheet.

Live: https://nicf8814.github.io/ghost-booth/

```
npm install
npm run dev     # local dev server
npm test
npm run build
```

Hold the title for 2 seconds to change the print caption, countdown, or fix
photo rotation. See CLAUDE.md for details.
